# Discord-бот для записи на игры HOI4

Бот создаёт анонсы игр с кнопками для записи на страны.

## Установка

1. Скопируйте `.env.example` в `.env`
2. Добавьте `DISCORD_TOKEN` в `.env`
3. `pip install -r requirements.txt`
4. `python bot.py`

## Команды

### Основные
- `/annonce` — создать анонс (выбор пресета, дата, мод, слоты)
- `/мои_записи` — ваши записи на игры
- `/stats` — топ по количеству записей

### Админ
- `/annonce_stop` — закрыть запись
- `/annonce_delete` — удалить анонс
- `/annonce_move` — перенести анонс в другой канал
- `/annonce_slots` — изменить слоты для страны
- `/config_log` — канал для лога записей
- `/config_role` — роль для записавшихся
- `/preset_save` — сохранить свой пресет

## Пресеты модов

TGR, Vanilla, Kaiserreich, R56, TWR, Equestria at War, Red Flood, Old World Blues

## Возможности

- Кнопки по странам или Select (при 21+ странах)
- Кнопка «В резерв» — запись в резервный список
- Кнопка «🔔 Напомнить» — пинг всех записавшихся
- Автосоздание ветки под анонсом (опция в форме)
- Лог записей в отдельный канал (если настроен)
- Роль для записавшихся (если настроена)
- Кастомные пресеты стран
- Изменение слотов на страну админом
